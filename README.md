🛒 বাজার দর (Bazar Dor)

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের বাজারদর জানুন সহজেই!

বাজার দর একটি ওয়েব-ভিত্তিক প্ল্যাটফর্ম, যেখানে ব্যবহারকারীরা বাংলাদেশের বিভিন্ন নিত্যপ্রয়োজনীয় পণ্যের বর্তমান বাজারমূল্য দেখতে পারবেন। পাশাপাশি আগের দিনের ও আগের সপ্তাহের দামের সঙ্গে তুলনা করে বাজারদরের পরিবর্তন সম্পর্কে জানতে পারবেন।

🚀 Technologies Used

Next.js – React-based web framework

React.js – Building interactive user interfaces

JavaScript – Application functionality

Tailwind CSS – Responsive and modern styling

HeroUI – UI components

Better Auth – User authentication

MongoDB – Database management

REST API – Fetching product and market price data

✨ Key Features

Product Price Tracking – View the latest prices of essential daily products.

Price Comparison – Compare today's prices with yesterday's and last week's prices.

Product Categories – Browse products by categories such as rice, vegetables, fish, and other essentials.

Product Details – View detailed product information, price history, and market information.

User Authentication – Create an account and securely sign in using Better Auth.
